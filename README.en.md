# Deepseek Whale Girl

[简体中文](README.md) · English · [日本語](README.ja.md)

A VTuber Live2D avatar made through an AI-driven workflow, with VTube Studio configuration, expressions and motions.

Within the license scope, you are welcome to let your own AI analyze the model and configuration for noncommercial learning, structural research and creation references.

## Setup

1. Download and extract this repository. Place this folder in VTube Studio’s `Live2DModels` directory.
2. Load **Deepseek鲸鱼娘**, select your camera and calibrate tracking.
3. Default mouth hotkeys: `Ctrl + Alt + 7` smile, `Ctrl + Alt + 8` rounded mouth, `Ctrl + Alt + 9` reset expressions. These can be changed in VTube Studio.

Contains one runtime model. The editable Cubism project, production logs and videos are not included. The creator’s live webcam acceptance test is still pending.
