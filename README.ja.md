# Deepseek クジラ娘

[简体中文](README.md) · [English](README.en.md) · 日本語

AI を活用したワークフローで制作した、VTuber 向けの Live2D モデルです。VTube Studio 設定、表情、モーションを同梱しています。

ライセンスの範囲内で、ご自身の AI にモデルや設定を分析させ、非営利の学習・構造研究・制作の参考として活用していただけます。

## 使い方

1. リポジトリをダウンロードして解凍し、このフォルダーを VTube Studio の `Live2DModels` 内に配置します。
2. **Deepseek鲸鱼娘** を読み込み、カメラを選択してトラッキングを調整します。
3. 口の初期ショートカット：`Ctrl + Alt + 7` 笑顔、`Ctrl + Alt + 8` 丸い口、`Ctrl + Alt + 9` 表情リセット。ソフト内で変更できます。

実行用モデルは1体のみです。Cubism 編集用プロジェクト、制作履歴、動画は含みません。制作者による実際のカメラ使用感の確認は未完了です。
