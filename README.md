# Deepseek鲸鱼娘

简体中文 · [English](README.en.md) · [日本語](README.ja.md)

通过 AI 工作流制作的 VTuber Live2D 模型，包含 VTube Studio 运行配置、表情与动作。

欢迎在许可范围内，让你自己的 AI 分析模型与配置，用于非商业学习、结构研究和制作参考。

## 使用

1. 下载本仓库并解压，将本文件夹放入 VTube Studio 的 `Live2DModels` 目录。
2. 在 VTube Studio 中载入 **Deepseek鲸鱼娘**，选择摄像头并校准面捕。
3. 默认嘴形快捷键：`Ctrl + Alt + 7` 微笑、`Ctrl + Alt + 8` 圆口、`Ctrl + Alt + 9` 恢复追踪。可在软件内修改。

本仓库仅含一个运行模型，不含 Cubism 可编辑工程、制作记录或视频。真人摄像头体验尚待制作者确认。
